# Programa de ponto (banco de horas)

Aplicação para registar ponto e gerir o banco de horas. Abre no Safari do iPad pelo link do GitHub Pages.

Os dados ficam guardados só neste dispositivo e neste navegador (localStorage). Não há nomes reais nem dados pessoais no ficheiro publicado. Os três colaboradores iniciais são exemplos fictícios; podes apagá-los e criar os teus.

Faz de vez em quando uma exportação de cópia de segurança dentro da app. Se apagares os dados do Safari, perdes os registos.
